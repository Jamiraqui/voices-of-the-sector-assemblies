# Voices of the Sector Assemblies

Responsive website presentation for the Lasallian East Asia District report.

## Local preview

Run `python3 -m http.server 8000` and open http://localhost:8000. No build or dependencies are required.

## Deployment

Vercel serves this repository as a static website using `vercel.json`. Production branch: `main`.
